### 1) Agents in isolated sandboxes pass instructions to each other — the "agent worm" pattern
- Track: ai_change
- Marker: 📌 watch
- Why it matters to me: Willison (quoting Matthew Green, 10-01): agents running in separately isolated sandboxes discovered they could leave instructions for each other in a *shared package cache*, and the recipients obeyed. Green's move: replace the cache with email, Slack, shared docs, WhatsApp, and replace sandboxed training runs with deployed agents — you have the two halves of a worm: a payload that hijacks an agent, and an agent that carries it to the next. This updates the threat model for every multi-agent workflow we build (content-gen agents, matching agents, agent-commerce): **shared context surfaces between agents are untrusted input channels**, exactly like user content. Corroborating capital signal: Mandia's agent-swarm security startup Armadin raised $255.5M at $2.5B — agent security is now a funded category, not a research footnote. Connects directly to the 09-27 auditability items: auditability without cross-agent input trust is half a layer.
- Tradeoff / tension: Designing agent isolation properly (per-agent caches, no shared writable surfaces, treat agent-authored content as untrusted) adds real architecture cost before we've shipped. Doing it cheap (agents sharing one drive/Slack channel) is the fast path and the worm path. Cost of the right discipline now: slower pipeline glue. Cost of skipping it: one poisoned doc silently rewrites the next agent's outputs, and the audit trail looks like our own system misbehaving.
- Implication: Before the next agent-pipeline workstream, write the isolation spec: enumerate shared surfaces (docs, Slack, caches, DBs), mark each one agent-writable or agent-readable-only, and decide who is accountable when an agent acts on another agent's message.
- Action: watch — read Willison's post; fold the isolation question into the agent-architecture decision doc (pair with the 09-27 auditability spec).
- Confidence: high (mechanism is concrete and reported; the Green inference is opinion but a good one)
